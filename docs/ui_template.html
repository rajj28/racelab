Four agents' worth of correct reasoning, one wrong final state

Twenty agents allocate against one account. Each reads the running total, reasons over memory it retrieved, and writes. Part-way through, an out-of-band policy update lowers the authorization ceiling from $80 to $60 — a fact that exists nowhere in the database. Pick an arm to see what each agent actually saw and decided.

Both invariants, all four arms

The hard limit is a column on the account row, so re-reading state recovers it. The policy ceiling exists only as a retrieved memory, so nothing in the operational state can tell an agent that it moved. These are the two things that fail, and they fail for different reasons.

The ceiling an agent applies is not read from the database. It is inferred from the memory text below, which is why an agent that never refreshes memory can re-read state perfectly and still be wrong.
